## 打开软件

从 [GitHub Releases](https://github.com/Symplatt/zhiling/releases/latest) 下载 **Zhiling-Setup-2.0.5.exe** 和 **Zhiling-Guide-2.0.5.txt**。在 Windows 10/11（64 位）上双击安装包，它会自动安装到当前用户目录、创建“织灵（桌面版）”快捷方式并打开软件。不需要 Python、Node.js、浏览器或联网下载依赖。以后双击该快捷方式即可。给别人使用时发送这两个文件即可；[简明安装与使用说明](docs/安装与使用说明.txt)也可在线阅读。

安装包不包含你的私人关系网。需要转移作品时，在原软件导出完整书架 JSON，然后在新电脑导入。卸载程序默认保留作品数据。

完整源代码本身不等于可直接运行的软件；开发源代码需 Node.js 和项目依赖。若复制包含 `织灵.exe`、`runtime`、`server`、`dist` 的完整浏览器版程序目录，也不需要另装 Python 或 Node.js。

双击桌面的 **织灵** 快捷方式即可。启动器会在后台启动本机服务，并用默认浏览器打开 `http://127.0.0.1:5173/`，无需运行命令或安装开发环境。

也可双击项目目录内的 `织灵.exe`。请保留其旁边的 `runtime`、`server`、`dist` 文件夹，不要只移动这一个启动器。桌面快捷方式指向 `E:\work-space\novel-atlas\织灵.exe`。

`release/织灵.exe` 是另附的 Electron 独立桌面窗口版本；桌面快捷方式使用的是**浏览器版**。

## 关系网书架

- 点击左上方当前关系网名称或 **切换关系网** 打开书架。
- 可建立、独立保存、搜索和切换 **1,000 张**关系网，已验证 120 张图的存储及重载。
- **新建关系网**不会覆盖当前图。输入名称后创建，无需填写简介。
- 导入单图 JSON 会新增一张关系网；导入完整书架会追加其中的全部关系网，不覆盖现有内容。
- 书架支持删除关系网，以及 **备份整个书架**。删除整个关系网前建议导出备份；角色和关系编辑支持会话内撤销。

## 图谱操作（2.0.2）

- 左侧提供 **自动布局、关系标签、添加关系**，关系网名称旁的铅笔用于重命名；顶部提供导入、导出、保存、设置和详情开关。
- 原图谱标题栏和工具栏已移除，画布直接衔接顶部导航。
- 滚轮缩放更灵敏；自动布局保留更宽间距，关系文字从 12 增至 15。
- 点击人物圆圈，当前角色显示较强光晕；与它直接相连的全部箭头和其他角色显示较弱高亮。点击其他角色更新高亮，点击画布空白处取消。
- 关系网不再包含简介字段。旧 JSON 仍可导入，人物小传、关系描述和其他扩展信息保留。

界面按导航、侧栏、画布、详情和各类对话框拆分到 `src/components`；图谱样式、布局、选中状态和图片导出分别放在 `src/graph`。`App.vue` 仅负责组装界面，状态通过有类型约束的 `workspaceContext.ts` 共享。

## 角色与关系

圆圈只显示姓名，不使用头像。旧文件中的头像字段会在升级时移除，其他人物信息保留，原始旧版浏览器存储不会删除。

新增或编辑角色时，标签用**空格**分隔：`侠客 仙子 金丹后期` 创建三个标签。重复标签自动去重。

角色档案的“编辑档案”位于右上角，与关闭按钮并列。关系中的主题色文字“〔本人〕”代表当前角色，统一放在另一位角色之后，箭头仍指向原来的关系目标；悬停显示具体姓名。其他角色即使真的叫“本人”，也按普通姓名显示，不加这对括号。圆圈内的长姓名会自动换行。

预设边框颜色始终可用，与自定义颜色在同一行显示，预设在前。点击末尾的“+”打开调色板，通过色块和色条选色，或输入 `#6B8E73`、`rgb(107, 142, 115)`、`107,142,115`，添加后保存角色。自定义颜色按添加顺序先进先出保留 7 种，重复添加不占位、不重排。颜色历史随整个书架保存和备份，队列淘汰不改变已有角色的颜色。

一个角色可以同时属于多个阵营，一个阵营也可以包含多个角色。在角色表单中点击阵营名称切换归属，输入新名称可添加阵营；没有归属的角色显示为“未分组”。旧文件的单个 `group` 会自动转换为 `groups` 数组。

添加关系时，两端的角色列表均按姓名拼音排序。新增人物的初始关系支持“新角色 → 所选角色”“新角色 ↔ 所选角色”和“所选角色 → 新角色”。角色档案底部的聚焦、删除按钮始终固定显示，不随关系列表滚动。

帮助窗口左下角标注 **© 2026 Symplatt 版权所有**。

关系有单向和双向两种。单向“青禾 → 月白，母亲”表示青禾是月白的母亲。两种方向都只有一个“关系名称”输入栏，例如填写“母女”“朋友”或“母亲/女儿”。已取消双向关系的模式选择。旧成对关系会自动合并为“母亲/女儿”，两边原有文字都保留，之后可在同一个输入栏编辑。

同一对人物可保存多种关系，每条关系可补充描述。点击节点或列表查看人物档案，点击连线或详情中的关系条目编辑关系。

## 悬停与图钉

- 鼠标悬停在角色圆圈上，在浏览器内容区域右上角显示关系窗口。
- 窗口列出该角色与**所有其他角色**的直接关系；没有记录的显示“暂无直接关系”。可搜索人物。
- 圆圈右上角出现图钉，点击后窗口固定，移开鼠标也不会消失。
- 再次点击同一图钉取消固定；窗口内也提供取消固定按钮。
- 已固定时，悬停另一个角色不会覆盖旧窗口，点击另一个角色的图钉才会替换。
- 点击窗口右上角叉号完全关闭窗口。始终只有一个窗口，关闭新窗口不会恢复旧窗口。

## 整图导出

顶部 **导出图片** 将整个关系网生成 PNG，包含全部节点、箭头和关系文字，不受当前阵营筛选、缩放或局部聚焦限制。导出不会改变屏幕上的筛选或位置。

导出保留当前手动编排的全部角色坐标与连线路径，不重新布局，不改变屏幕上的坐标、缩放和位置，使用当前主题配色与关系标签显示设置。一般以两倍比例输出；特别大的图谱会限制为最长边 8,000 像素、最多约 3,200 万像素以控制内存。空图无法导出。

浏览器版使用浏览器下载功能保存图片；Electron 版弹出原生保存对话框。JSON 导出与图片导出相互独立。

## 保存与旧数据

浏览器启动器版的数据保存在项目目录 `data/library.json`，上一份有效数据保存在 `data/library.json.bak`。请定期使用书架内的备份按钮保存独立 JSON。

首次打开同一浏览器、同一地址时，应用会迁移旧版 `novel-atlas-v1` 本地数据；升级开发过程中产生的 IndexedDB 书架也会在首次连接本地服务时迁入 JSON。迁移成功前不删除旧数据。请继续使用原浏览器及 `127.0.0.1` 地址，以访问该浏览器原有数据。

Electron 版保存在其应用用户数据目录的 `workspace/library.json`，会尝试读取旧版 `atlas.json`。**浏览器版和 Electron 版各自保存书架**；通过导出/导入完整书架在两者间迁移。

同一浏览器版书架被多个标签页同时修改时，过期窗口会提示冲突，避免直接覆盖其他窗口的内容。请先导出当前未保存图谱，再刷新加载最新书架。

## 操作与布局

图谱设置中的“排列稀疏程度”提供 1–5 档，以原有布局为第 1 档，间距依次为基准的 1.0、1.2、1.4、1.6、1.8 倍。切换时直接调整当前排列的间距并适应画布；自然分布与环形分布、阵营筛选后的自动布局均沿用该档位。选择随本机书架自动保存，旧书架默认第 1 档。PNG 导出仍保留当前排列。

滚轮缩放、拖动空白处平移，拖动角色微调位置。自动布局支持自然分布与环形；切换阵营或恢复全部阵营时重新布局并适应画布。关系线始终保持直线，自动布局通过调整节点位置减少无关角色遮挡连线。同一对人物的多条关系文字分行显示；自身关系只显示文字，不画弯曲回环。密集连线仍可能相互交叉，可隐藏标签、缩放或聚焦查看。

新增角色等对话框使用真实浏览器视口居中，内容过多时在弹窗内滚动。主界面占满窗口，不预留右侧空白。点击角色打开的档案栏可关闭。

快捷键：`Ctrl+S` 保存书架；`Ctrl+Z` 撤销；`Ctrl+Y` / `Ctrl+Shift+Z` 重做；`Esc` 关闭对话框。文本输入保留原生撤销。每图当前会话最多 30 次撤销，切换关系网会清空撤销记录。

## JSON 示例

单图沿用 `version: 1`，单向和双向都只需一个 `label`：

```json
{
  "version": 1,
  "title": "我的故事",
  "characters": [
    { "id": "a", "name": "青禾", "groups": ["云岫门", "花家"], "tags": ["侠客", "仙子", "金丹后期"] },
    { "id": "b", "name": "月白" }
  ],
  "relations": [
    {
      "id": "r1",
      "from": "a",
      "to": "b",
      "direction": "two-way",
      "label": "母女"
    }
  ]
}
```

旧文件中的 `mode` 和 `reverseLabel` 会在读取时转换为单一 `label`，不再写入新文件。角色 ID 必须唯一，所有关系端点必须存在。单图最多 2,000 角色、20,000 关系；书架最多 1,000 图、JSON 文件最大 128 MB。完整书架格式为 `version: 2`，含 `graphs`、`activeId`、`theme`。

## 开发

Vue 3 + TypeScript + Vite + Cytoscape.js/fCoSE；本地 HTTP 服务仅依赖随附 Node 运行时；另附 Electron 版本。

```powershell
npm ci
npm run dev
npm run build
npm test
npm start
npm run pack
npm run pack:release
```

开发用 Vite 与正式本地服务都使用 5173 端口，不能同时运行。开发预览没有本地 API 时使用 IndexedDB。原生浏览器启动器源码为 `build/BrowserLauncher.cs`。桌面快捷方式启动时不弹出终端。

验证记录见 `VERIFICATION.md`。

从源码生成安装包的逐步教程见 [打包教程](docs/从源码打包安装包.md)。打包命令只在本机生成文件，不自动发布 GitHub Release。
