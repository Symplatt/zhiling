# 织灵 · 角色关系网

## 打开软件

双击桌面的 **织灵** 快捷方式即可。启动器会在后台启动本机服务，并用默认浏览器打开 `http://127.0.0.1:5173/`，无需运行命令或安装开发环境。

也可双击项目目录内的 `织灵.exe`。请保留其旁边的 `runtime`、`server`、`dist` 文件夹，不要只移动这一个启动器。桌面快捷方式指向 `E:\work-space\novel-atlas\织灵.exe`。

`release/织灵.exe` 是另附的 Electron 独立桌面窗口版本；桌面快捷方式使用的是**浏览器版**。

## 关系网书架

- 点击左上方当前关系网名称或 **切换关系网** 打开书架。
- 可建立、独立保存、搜索和切换 **1,000 张**关系网，已验证 120 张图的存储及重载。
- **新建关系网**不会覆盖当前图。输入名称与简介后创建。
- 导入单图 JSON 会新增一张关系网；导入完整书架会追加其中的全部关系网，不覆盖现有内容。
- 书架支持删除关系网，以及 **备份整个书架**。删除整个关系网前建议导出备份；角色和关系编辑支持会话内撤销。

## 角色与关系

圆圈只显示姓名，不使用头像。旧文件中的头像字段会在升级时移除，其他人物信息保留，原始旧版浏览器存储不会删除。

新增或编辑角色时，标签用**空格**分隔：`侠客 仙子 金丹后期` 创建三个标签。重复标签自动去重。

关系有单向和双向两种。单向“青禾 → 月白，母亲”表示青禾是月白的母亲。双向关系可选择：

1. **分别填写**：A 对 B 为“母亲”，B 对 A 为“女儿”。图上显示 `母亲/女儿`，左项对应起点 A，右项对应终点 B。
2. **共同关系**：填写“母女”，图上显示 `母女`。

同一对人物可保存多种关系，每条关系可补充描述。点击节点或列表查看人物档案，点击连线或详情中的关系条目编辑关系。

## 悬停与图钉

- 鼠标悬停在角色圆圈上，在浏览器内容区域右上角显示关系窗口。
- 窗口列出该角色与**所有其他角色**的直接关系；没有记录的显示“暂无直接关系”。可搜索人物。
- 圆圈右上角出现图钉，点击后窗口固定，移开鼠标也不会消失。
- 再次点击同一图钉取消固定；窗口内也提供取消固定按钮。
- 已固定时，悬停另一个角色不会覆盖旧窗口，点击另一个角色的图钉才会替换。
- 点击窗口右上角叉号完全关闭窗口。始终只有一个窗口，关闭新窗口不会恢复旧窗口。

## 整图导出

顶部 **导出图片** 将整个关系网生成 PNG，包含全部节点、箭头和关系文字，不受当前阵营筛选、缩放或局部聚焦限制。导出不会改变屏幕上的筛选或位置。

导出时为完整图谱重新布局，使用当前主题配色。一般以两倍比例输出；特别大的图谱会限制为最长边 8,000 像素、最多约 3,200 万像素以控制内存。空图无法导出。

浏览器版使用浏览器下载功能保存图片；Electron 版弹出原生保存对话框。JSON 导出与图片导出相互独立。

## 五种主题

打开 **显示设置** 或 **图谱设置**：

| 主题   | 风格                 |
| ------ | -------------------- |
| 黑白灰 | 白灰背景，石墨色重点 |
| 浅草   | 浅绿纸面，草木绿     |
| 桃粉   | 桃粉背景，玫瑰色重点 |
| 碧蓝   | 浅蓝背景，海蓝色重点 |
| 金夜   | 深色背景，暖金色重点 |

主题覆盖界面、对话框、图谱及导出图片，并随书架保存。角色自己的阵营颜色仍保留。

## 保存与旧数据

浏览器启动器版的数据保存在项目目录 `data/library.json`，上一份有效数据保存在 `data/library.json.bak`。请定期使用书架内的备份按钮保存独立 JSON。

首次打开同一浏览器、同一地址时，应用会迁移旧版 `novel-atlas-v1` 本地数据；升级开发过程中产生的 IndexedDB 书架也会在首次连接本地服务时迁入 JSON。迁移成功前不删除旧数据。请继续使用原浏览器及 `127.0.0.1` 地址，以访问该浏览器原有数据。

Electron 版保存在其应用用户数据目录的 `workspace/library.json`，会尝试读取旧版 `atlas.json`。**浏览器版和 Electron 版各自保存书架**；通过导出/导入完整书架在两者间迁移。

同一浏览器版书架被多个标签页同时修改时，过期窗口会提示冲突，避免直接覆盖其他窗口的内容。请先导出当前未保存图谱，再刷新加载最新书架。

## 操作与布局

滚轮缩放、拖动空白处平移，拖动角色微调位置。自动布局支持自然分布与环形；底部阵营图例和左侧筛选可查看局部。节点排列后检查包含文字边界的间距。密集连线仍可能交叉，可隐藏标签、缩放或聚焦查看。

新增角色等对话框使用真实浏览器视口居中，内容过多时在弹窗内滚动。主界面占满窗口，不预留右侧空白。点击角色打开的档案栏可关闭。

快捷键：`Ctrl+S` 保存书架；`Ctrl+Z` 撤销；`Ctrl+Y` / `Ctrl+Shift+Z` 重做；`Esc` 关闭对话框。文本输入保留原生撤销。每图当前会话最多 30 次撤销，切换关系网会清空撤销记录。

## JSON 示例

单图沿用 `version: 1`，双向关系增加 `mode` 和 `reverseLabel`：

```json
{
  "version": 1,
  "title": "我的故事",
  "description": "关系网简介",
  "characters": [
    { "id": "a", "name": "青禾", "tags": ["侠客", "仙子", "金丹后期"] },
    { "id": "b", "name": "月白" }
  ],
  "relations": [
    {
      "id": "r1",
      "from": "a",
      "to": "b",
      "direction": "two-way",
      "mode": "paired",
      "label": "母亲",
      "reverseLabel": "女儿"
    }
  ]
}
```

共同关系用 `mode: "shared"` 和 `label: "母女"`。旧双向关系默认视为共同关系。角色 ID 必须唯一，所有关系端点必须存在。单图最多 2,000 角色、20,000 关系；书架最多 1,000 图、JSON 文件最大 128 MB。完整书架格式为 `version: 2`，含 `graphs`、`activeId`、`theme`。

## 开发

Vue 3 + TypeScript + Vite + Cytoscape.js/fCoSE；本地 HTTP 服务仅依赖随附 Node 运行时；另附 Electron 版本。

```powershell
npm ci
npm run dev
npm run build
npm test
npm start
npm run pack
```

开发用 Vite 与正式本地服务都使用 5173 端口，不能同时运行。开发预览没有本地 API 时使用 IndexedDB。原生浏览器启动器源码为 `build/BrowserLauncher.cs`。桌面快捷方式启动时不弹出终端。

验证记录见 `VERIFICATION.md`。
