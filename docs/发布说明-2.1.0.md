# 织灵 V2.1.0

- 同一对人物的每种关系各占一条连线，多条关系可以用弧线分开显示；只有一条关系时保持直线。
- 图谱设置新增独立的 1–5 档角色头像大小，可配合排列稀疏程度调整人物在画面中的占比。
- 支持上传、更换、移除角色头像，自动居中裁剪为最大正方形；圆形显示图片，姓名显示在旁边。头像随 JSON 一起导出。
- 手动位置自动保存到本机，重新打开或切换关系网后恢复；单图和整书架导出的 JSON 都不包含本机坐标。
- 区分未提交的表单、等待保存、保存中、保存失败与已保存，修复拖动位置未保存的问题。
- 调整重命名铅笔的垂直位置，隐藏角色档案侧栏滚动条，更新角色编辑窗口。
- 修复后台导出头像的加载等待，PNG 保留当前人物位置、图片和多条关系线。

## 安装

Windows 10/11，64 位。下载 `Zhiling-Setup-2.1.0.exe`，双击安装；以后从桌面“织灵（桌面版）”打开。运行不需要 Python 或 Node.js。

更新前先备份整个书架，关闭旧版后运行新版安装包。安装包不包含私人作品。`Zhiling-Guide-2.1.0.txt` 为简明说明，`SHA256SUMS.txt` 为文件校验值。

角色和关系提交后会自动保存，无需再点顶部保存。表单中尚未提交的内容不会写入作品；状态栏会明确提示。
