# 织灵 2.1.1

## 新增

- PNG、JSON 分别设置默认导出目录及是否每次询问；自动导出遇到同名文件会编号。
- 角色档案固定按钮；纯图谱全屏（Esc / F11 退出）。
- 新建时复制已有关系网，名称可继续编辑，角色、头像、关系和布局一并复制。
- CHANGELOG 从本版本起记录更新；规范后续提交与代码注释。

## 更新与修复

- 头像大小同步调整关系文字、线宽与箭头。
- 阵营切换不再打乱布局；新增角色尽量保留原有坐标。
- 帮助版权与“开始创作”按钮底部对齐；README 补充设计与开发署名。
- 右下角适应画布按钮替换为全屏按钮。

## 安装与更新

下载 **Zhiling-Setup-2.1.1.exe**，双击自动安装，适用于 Windows 10/11 x64，无需 Python 或 Node.js。简明说明见 **Zhiling-Guide-2.1.1.txt**。

更新前保存并导出书架备份，关闭旧版再安装。同一账户升级保留本机作品。安装包不包含私人作品；换电脑用 JSON 迁移，导出目录和本机坐标不包含在 JSON 中。

浏览器支持目录访问时可选择文件夹；不支持时下载位置由浏览器管理。桌面版支持完整导出设置。
