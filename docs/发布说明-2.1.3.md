# 织灵 2.1.3

## 新增

- 进入全屏时显示“按 ESC 退出”，约 3 秒后自动消失；每次重新进入都会提示。

## 更新

- 有头像角色的姓名移至头像下方居中显示，PNG 导出采用相同位置。
- 第 1 档自动布局更紧凑，环形排列不再随窗口大小扩大；减少自然布局的留白。已有关系网点击一次“自动布局”应用新排列，原有手动坐标不会在打开或筛选时被重排。
- 导出设置以路径为主要内容，文件夹按钮及询问开关改为次要控件。
- 图谱设置的“完成”按钮始终位于窗口右下角，无需滚动到底部。

## 安装与更新

下载 **Zhiling-Setup-2.1.3.exe**，双击安装。适用于 Windows 10/11 x64，无需 Python 或 Node.js。使用说明见 **Zhiling-Guide-2.1.3.txt**。

更新前保存并导出书架备份，关闭旧版后运行安装包。同一 Windows 账户升级保留作品；安装包不包含私人关系网。
