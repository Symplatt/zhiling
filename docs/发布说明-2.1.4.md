# 织灵 2.1.4

- 头像第 3 档等于此前第 1 档：1–5 档为基准的 60%、80%、100%、120%、140%；关系文字和线条同步变化。
- 稀疏程度第 3 档等于此前第 5 档，其他档位同样按新基准每档增减 20%。未设置档位时默认第 3 档。
- 图谱设置加宽、增加两侧留白，完成按钮始终固定在右下角。
- 黄金夜所有滚动区域改用低亮度滚动条。
- 不再逐版本生成 TXT 文档，安装及使用方法见 [README](https://github.com/Symplatt/zhiling#readme)。

本次发布也包含此前尚未发布到 Release 的 2.1.3 修改：头像姓名居下、全屏退出提示、紧凑自动布局和导出设置视觉层级调整。

下载 **Zhiling-Setup-2.1.4.exe** 后双击安装，适用于 Windows 10/11 x64，无需 Python 或 Node.js。更新前保存作品、导出 JSON 备份并关闭旧版。

已有档位编号和手动位置保留；按新的档位含义选择适合的大小，点击“自动布局”应用新的排列间距。
