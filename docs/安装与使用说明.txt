织灵 2.0.5：安装与使用说明
© 2026 Symplatt 版权所有

先看这三句话
1. 下载 Zhiling-Setup-2.0.5.exe，双击，等待自动安装完成。
2. 以后双击桌面的“织灵（桌面版）”使用，不用反复运行安装包。
3. 重要作品记得备份 JSON。其他功能可以边点边摸索。

一、下载和安装
官方下载：https://github.com/Symplatt/zhiling/releases/latest
打开页面，在 Assets（附件）中下载 Zhiling-Setup-2.0.5.exe。
不要下载 Source code，那是给开发者看的源代码。

适用于 Windows 10/11 的 64 位电脑，不适用于手机、Mac 或 32 位 Windows。
下载后双击安装程序即可，不用选择安装目录，不用安装 Python、Node.js 等环境。
安装包已包含运行环境，安装时无需联网下载组件。等待几十秒到几分钟，不要反复双击。
安装完成会自动打开软件；桌面没找到快捷方式时，按 Windows 键搜索“织灵”。

出现“未知发布者”或“Windows 已保护你的电脑”：软件暂未签名。
请先确认来自上面的官方地址；确认来源后，如有“更多信息 → 仍要运行”，可选择继续。
如果安全软件明确报毒或不允许继续，不要关闭防护，请把提示截图反馈给作者。
双击没有反应时先等一两分钟；仍失败，重新下载完整安装包并检查系统是否为 Windows 10/11 64 位。

二、更新和搬家
更新前在旧版保存作品，备份整个书架，然后关闭织灵，再运行新版安装程序。
同一 Windows 账户下更新桌面版会保留作品。

换电脑或从浏览器版搬到桌面版：
1. 在原软件点击左上角关系网名称 →“备份整个书架”，保存 JSON 文件。
2. 把 JSON 复制到新电脑，在新软件顶部点“导入(Json)”→ 选择文件 →“确认导入”。
导入会追加关系网，不覆盖已有故事；同一文件不要反复导入。
浏览器版和桌面版分别保存作品。安装包不含私人作品，也不会自动同步作品。

三、开始使用
新建关系网：点击左上角关系网名称 →“+”→ 输入名称 → 创建。
新增人物：左侧“添加角色”。标签用空格分隔，如“侠客 仙子 金丹后期”。
添加关系：左侧“添加关系”，选择两端人物、单向或双向，输入关系名称并保存。
修改人物：点人物圆圈，在右侧角色档案右上角点“编辑档案”。
“〔本人〕”是主题色文字，表示当前查看的角色；鼠标放上去能看到具体名字。
真的叫“本人”的其他角色按普通姓名显示，不加这对括号。

滚轮缩放；拖动画布空白处移动；左侧“自动布局”重新排列；右下角“适应画布”查看全图。
顶部“图谱设置”切换主题：黑白灰、黄金夜、浅草、碧蓝、桃粉。
角色边框可用预设颜色，也可输入 #6B8E73 或 rgb(107, 142, 115)，点“使用颜色”再保存。
自定义颜色按添加顺序保留最近 7 种，左旧右新；重复添加不重排，也不影响已设置的角色颜色。

四、保存和备份
平时会自动保存；退出前确认底部显示“已自动保存”，也可点顶部“保存”。
如果保存失败，先导出 JSON 备份，不要直接关闭。
“导出图片(png)”：保存整张关系网图片，用来分享和查看。
“导出(Json)”：备份当前关系网，以后可以继续编辑。
左上角关系网列表 →“备份整个书架”：一次备份所有作品。
图片不能代替 JSON 备份。作品只保存在本机，建议定期把 JSON 复制到其他磁盘或备份设备。

五、帮助和卸载
顶部问号查看帮助；遇到问题可在 GitHub 仓库的 Issues 中反馈，附操作步骤和截图。
卸载：Windows 设置 → 应用 → 已安装的应用 → 织灵 → 卸载。
卸载前先备份；程序默认保留作品数据。

记住：双击安装包安装，以后双击桌面快捷方式使用，重要作品备份 JSON。
