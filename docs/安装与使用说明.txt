一、安装
1. 双击随附的“织灵-安装程序-2.0.6.exe”。
2. 等待安装完成，软件会自动打开，并创建“织灵（桌面版）”快捷方式。
3. 以后双击桌面快捷方式使用，不必再运行安装包。

适用于 Windows 10/11 的 64 位电脑。不需要安装 Python、Node.js 或其他运行环境，安装时也不用联网下载组件。
程序自动安装到当前用户目录，不用选择路径。开始菜单中搜索“织灵”也能打开。
给别人使用时，把安装程序和这份说明一起发给对方即可。安装包不包含你的作品。
项目主页：https://github.com/Symplatt/zhiling
公开版本下载：https://github.com/Symplatt/zhiling/releases
GitHub 的 Source code 是源代码，不是安装包；各版本的安装包请在 Assets 中查看。

二、更新和换电脑
更新前先在旧版保存，并在左上角关系网书架中“备份整个书架”，然后关闭软件，运行新版安装程序。同一 Windows 账户下更新桌面版会保留作品。
换电脑时，把备份的 JSON 文件带过去，在新软件顶部点击“导入(Json)”并确认导入。
导入会追加关系网，不覆盖原有作品，同一文件不要反复导入。
浏览器版与桌面版各自保存作品，需要用 JSON 导出、导入来迁移。

三、常用操作
新建关系网：点击左上角关系网名称，打开书架后点击“+”。
新增人物：点击左侧“添加角色”。标签用空格分隔，比如“侠客 仙子 金丹后期”。
阵营：一个人物可加入多个阵营，点击阵营名选择或取消，也可以输入新阵营名称后添加。
颜色：预设颜色与最近 7 个自定义颜色放在同一行；点击末尾“+”，用色块、色条选色，或输入 RGB、十六进制颜色代码。添加颜色后保存角色。
新增关系：点击“添加关系”，按拼音排序的列表选择两端人物，再填写关系名。
新增人物时可同时建立初始关系，支持新人物指向已有角色、反向指向，以及双向关系。
编辑人物：点击人物圆圈，在右侧档案右上角点击“编辑档案”。
关系列表中的“〔本人〕”表示当前查看的角色，放在另一位角色之后；箭头保持真实方向。

滚轮缩放，拖动空白处移动画布，拖动圆圈调整位置。
“自动布局”重新排列。切换阵营筛选时也会自动布局，并让可见角色完整显示。
关系线保持直线。人物太多时可筛选阵营或使用档案底部的“聚焦一度关系”。
顶部设置可切换黑白灰、黄金夜、浅草、碧蓝、桃粉五种主题。

四、保存和导出
平时自动保存，退出前确认底部显示“已自动保存”，也可以点击顶部“保存”。
“导出图片(png)”保存整张关系网，保留手动编排的位置，不重新布局。
“导出(Json)”备份当前关系网；书架中的“备份整个书架”备份全部作品。
图片不能代替 JSON 备份。重要作品请定期把 JSON 复制到其他磁盘或备份设备。
如果保存失败，先导出 JSON，不要直接关闭软件。

五、遇到问题
双击无反应：先等待一两分钟；仍无反应，检查安装包是否完整、电脑是否为 Windows 10/11 64 位。
提示未知发布者：本软件尚未签名，请核实文件来源后再决定是否继续。不要关闭安全防护。
顶部问号可查看帮助；问题可在项目主页的 Issues 中反馈，附操作步骤和截图。
卸载：Windows 设置 → 应用 → 已安装的应用 → 织灵 → 卸载。卸载前先备份，程序默认保留作品数据。
